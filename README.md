# Personal Portfolio

A modern, responsive developer portfolio built with React to showcase projects, skills, resume, and contact information.

## Tech Stack

- React 18
- React Bootstrap
- React Router DOM v6
- React Icons
- Typewriter Effect
- React Parallax Tilt
- React GitHub Calendar
- React TSParticles
- React PDF

## Pages

| Route | Description |
|-------|-------------|
| `/` | Home |
| `/about` | About me |
| `/project` | Projects |
| `/resume` | Resume |

## Getting Started

```bash
npm install --legacy-peer-deps
npm start
```

Open [http://localhost:3000](http://localhost:3000) to view in the browser.

## Scripts

| Command | Description |
|---------|-------------|
| `npm start` | Run in development mode |
| `npm run build` | Build for production |
| `npm test` | Run tests |

## Docker Deployment

```bash
docker compose up --build
```

Open [http://localhost:8080](http://localhost:8080).
