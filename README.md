# Portfolio

A personal portfolio website built with React.

## Tech Stack

- React 18
- React Bootstrap
- React Router DOM
- React Icons
- Typewriter Effect
- React Parallax Tilt
- React GitHub Calendar
- React TSParticles

## Getting Started

```bash
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

## Scripts

| Command | Description |
|---------|-------------|
| `npm start` | Run in development mode |
| `npm run build` | Build for production |
| `npm test` | Run tests |
